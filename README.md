# Rasavin | رساوین

نرم‌افزار فارسی مدیریت مراجعین برای مطب‌ها و مراکز خدماتی؛ نسخه نخست برای Windows و استفاده آفلاین.

## وضعیت پروژه
**Desktop MVP (preview)** — ثبت مراجعین، خدمات، مراجعه‌ها، دریافتی‌ها و پیگیری‌ها با SQLite؛ صفحه داشبورد راست‌به‌چپ و تنظیم نام مطب.

این نسخه هنوز برای نگهداری اطلاعات واقعی بیماران آماده انتشار تجاری نیست (پشتیبان‌گیری و امنیت عملیاتی نیازمند تکمیل است).

## راه‌اندازی

نیازمندی‌ها: Node.js LTS، Rust، پیش‌نیازهای Tauri 2 روی ویندوز شامل Microsoft C++ Build Tools و WebView2.

```bash
npm install
npm run icons
npm run desktop
```

برای بررسی صرفاً رابط کاربری در مرورگر:
```bash
npm run dev
```
حالت مرورگر فقط پیش‌نمایش موقتی است؛ اطلاعات در حافظه ذخیره می‌شود و با Refresh از بین می‌رود. ذخیره‌سازی دائمی SQLite فقط در اپ Tauri فعال است.

ساخت نسخه ویندوزی (روی Windows):
```bash
npm run icons
npm run tauri build
```
خروجی‌های NSIS (.exe) و MSI در `src-tauri/target/release/bundle/` قرار می‌گیرند.

## تعهد محصول
- قابلیت‌های پایه و دسترسی به اطلاعات محلی هرگز مشروط به پرداخت/اتصال نیست.
- آپدیت‌های رفع باگ و امنیتی برای همه کاربران رایگان است.
- قابلیت‌های Cloud، SMS، AI بعداً و به‌صورت اختیاری ارائه می‌شوند.
- آپدیت داخل برنامه فقط پس از پیکربندی امضای معتبر و HTTPS فعال می‌شود.
