# Rasavin | رساوین

نرم‌افزار فارسی مدیریت مراجعین، خدمات، دریافتی‌ها و پیگیری‌ها برای مطب‌ها و مراکز خدماتی.

**اصول محصول**
- نسخه پایه و دسترسی به داده‌های محلی همیشه بدون اشتراک فعال است.
- اصلاحات امنیتی و رفع خطا برای همه کاربران رایگان است.
- اول آفلاین (Windows / SQLite)، سپس اتصال اختیاری به ابر، SMS و AI.
- انتشار آپدیت‌ها فقط با امضای معتبر؛ هیچ کلید خصوصی در مخزن قرار نمی‌گیرد.

کد اولیه برنامه در شاخه توسعه قرار می‌گیرد و پس از بررسی وارد `main` می‌شود.
